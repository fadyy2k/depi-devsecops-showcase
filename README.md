# DEPI DevSecOps Project Showcase — Vercel App

A Vercel-ready React + Vite visual documentation portal for the DEPI DevSecOps Project — MIND Notes App.

## Local Run

```bash
npm install
npm run dev
```

## Vercel Settings

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`

## Security Note

Do not publish real passwords, tokens, SSH keys, DockerHub tokens, SonarQube tokens, or ArgoCD admin passwords in this public app.
